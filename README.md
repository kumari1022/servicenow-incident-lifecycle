# Incident Management Lifecycle Automation

## Project Overview

This project demonstrates an end-to-end Incident Management lifecycle
implemented in ServiceNow.

The project manages incidents from creation and classification to
assignment, escalation, investigation, change integration, knowledge
management, child incident management, SLA tracking, and final resolution.

## Objectives

- Create and classify incidents
- Assign incidents to the correct support team
- Escalate incidents when required
- Use Knowledge articles during troubleshooting
- Create and link Change Requests
- Manage Child Incidents
- Track SLAs
- Resolve incidents
- Support multi-team collaboration

## Change Integration

A Change Request was created and linked to the incident.

- Change Request: CHG0030001

This connects the incident with the change management process.

## Child Incident Management

A child incident was created under the parent incident.

The child incident is connected to the parent incident and follows
the configured resolution process.

## Knowledge Management

Knowledge articles are used during incident troubleshooting.

After resolving the issue, the solution was also added as a
Knowledge article for future reference.

## SLA Tracking

Task SLA records are associated with the incident to monitor
response and resolution time.
